# mbswath2las — スワス水深の測深点を LAS 1.4 点群に出力

`mbswath2las` は、MB-System が対応する任意のフォーマットのスワス水深データを
読み込み、有効な測深点を 1 点ずつ LAS 1.4 ファイルに書き出します。
MB-System のフォーマットを読めない点群ビューア、GIS、処理ツール（例：
CloudCompare、QGIS、PDAL）にマルチビームの測深点を読み込むために使用します。
通常は `mbprocess` でデータの編集と処理を終えた後に実行します。

## 書式

    mbswath2las [-A -Bbegintime -Eendtime -Fformat -Iinputfile -Jprojection -Llonflip -Ooutputfile -P -Rwest/east/south/north -Sspeedmin -Ttimegap -V -H]

ロングオプション：`--use-amplitude`（`-A`）、`--begin-time`（`-B`）、
`--end-time`（`-E`）、`--format`（`-F`）、`--input`（`-I`）、`--projection`
（`-J`）、`--lonflip`（`-L`）、`--output`（`-O`）、`--write-prj`（`-P`）、
`--bounds`（`-R`）、`--speed-minimum`（`-S`）、`--time-gap`（`-T`）、
`--verbose`（`-V`）、`--help`（`-H`）。

## 説明

各測深点の位置は、航法、方位、ビームの横方向・前後方向距離から `mblist` と
同じ方法で計算されます。ビームフラグで不良とされたビームは出力されません。
LAS の標高は上向き正のため、LAS の標高（Z）は水深の符号を反転した値になります。
既定では位置は地理座標の経度・緯度（WGS84）です。`-J` を指定すると、選択した
投影座標系の東距・北距（m）になります。座標系は OGC WKT レコードとして LAS
ファイルに格納され、`-P` を指定すると各 LAS ファイルの隣に Esri 形式の `.prj`
ファイルも書き出されます。

入力は 1 つのスワスファイルまたはデータリストです。`-O` を指定しない場合、
入力ファイルごとに LAS ファイルが作成され、名前は入力の MB-System
フォーマット拡張子を `.las` に置き換えたものになります（例：
`0001_20250101_000000.mb59` から `0001_20250101_000000.las`。認識できる拡張子が
ない場合は名前の末尾に `.las` が付きます）。`-O` を指定すると、すべての
測深点が 1 つの LAS ファイルにまとめられます。

処理時間を短縮するため、入力ファイルに水深のみの `.fbt` ファイルがあれば
それを読み込みます。`.fbt` ファイルには振幅がないため、LAS の強度（intensity）
フィールドは 0 になります。`-A` を指定すると元のスワスファイルが読み込まれ、
ビームごとの振幅が入力全体の振幅範囲から LAS の範囲 0-65535 に線形変換されます
（相対値であり、較正された反射強度ではありません）。`-J` または `-A` を
指定した場合は、不足または古い `.inf`、`.fbt`、`.fnv` ファイルが先に作成され、
調査範囲と振幅範囲は `.inf` ファイルから取得されます。

LAS ファイルはポイントデータレコード形式 1 を使用します。X/Y の分解能は
1e-7 度（地理座標）または 0.01 m（投影座標）、Z の分解能は 0.001 m です。
GPS 時刻フィールドには各測深点の Unix 時刻が入り、本来の GPS 時刻ではありません。

## 主なオプション

- `-I<file>` — 入力スワスファイルまたはデータリスト。既定：`datalist.mb-1`。
- `-F<format>` — 入力フォーマット番号。負の値はデータリストを示します。
  既定：ファイル名の拡張子から推定。
- `-O<file>` — すべての測深点をこの 1 つの LAS ファイルに書き出します。
- `-J<projection>` — 投影座標で書き出します：`U` または `UTM` で調査範囲中心の
  UTM ゾーン、`UTM31N` 形式のゾーン名、`L` または `LTM` で調査範囲中心の
  ローカル横メルカトル、`LTM<lon0>/<lat0>` で原点を明示、または EPSG コードや
  PROJ 定義。既定：地理座標 WGS84。
- `-P` — `.prj` ファイルも書き出します（LAS ファイル名の `.las` を `.prj` に
  置き換えた名前）。
- `-A` — ビームの振幅から LAS の強度フィールドを設定します（`.fbt` ではなく
  元のファイルを読み込みます）。
- `-R<west>/<east>/<south>/<north>` — この範囲内のデータだけを出力します。
- `-B<yr/mo/da/hr/mn/sc>` / `-E<yr/mo/da/hr/mn/sc>` — この時間内のデータだけを
  出力します。
- `-S<speed>` — 船速がこの値（km/h）未満のピングを除外します。既定：0。
- `-T<timegap>` — データの欠測として報告する時間間隔（分）。既定：1。
- `-L<lonflip>` — 経度の範囲：`-1` = -360～0、`0` = -180～180、`1` = 0～360。
  既定：`mbdefaults` の設定値。
- `-V` — 詳細表示。実際に使用した座標系、各出力ファイル名、書き出した点数を
  表示します。

## 使用例

スワスファイル 1 本を `0002_20180911_020351_EX1811_MB.las` に変換します。

    mbswath2las -I 0002_20180911_020351_EX1811_MB.mb88 -F88

データリストの各ファイルをそれぞれ LAS ファイルに変換し、進捗を表示します。

    mbswath2las -I datalist.mb-1 -V

データリストの全測深点を UTM の 1 つの LAS ファイルにまとめ、ArcGIS 用の
`.prj` ファイルも作成します。

    mbswath2las -I datalist.mb-1 -JUTM -P -O survey.las

ローカル横メルカトル投影を使い、振幅から強度を設定します。

    mbswath2las -I datalist.mb-1 -JLTM -A -O survey.las

## 注意

- `-O` を指定しない場合、各 LAS ファイルは入力ファイルと同じ場所に書き出され
  ます。空白を含むパスは引用符で囲んでください。
- 先に `mbprocess` を実行し、データリストが処理済みファイルを選択するように
  してください。そうすることで、出力される測深点に編集や補正が反映されます。
