# mbprocess — 編集・航法・音速・各種補正をスワスファイルに適用

`mbprocess` は MB-System の中心となる処理プログラムです。生のスワスファイルを読み込み、そのファイルに設定された水深編集、航法・姿勢のマージ、音速プロファイルを用いたレイトレーシングによる水深の再計算、バイアス・喫水・潮汐補正、振幅／サイドスキャン補正を 1 回の処理で適用し、処理済みのコピーを書き出します。通常は編集（`mbclean`、`mbvoxelclean` など）と `mbset` によるパラメータ設定の後、`mbgrid` や `mbmosaic` によるグリッド作成の前に実行します。

## 書式

    mbprocess -Iinfile [-C -Fformat -N -Ooutfile -P -S -T -V -H]
        --format=value {-Fvalue}
        --force {-P}
        --help {-H}
        --input=file {-Ifile}
        --output=file {-Ofile}
        --print-status {-S}
        --strip-comments {-N}
        --test {-T}
        --threads=value {-Cvalue}
        --verbose {-V}

## 説明

各ファイルに対する処理内容は、スワスファイル名に `.par` を付けた名前のテキストのパラメータファイルで制御されます（`survey.mb58` なら `survey.mb58.par`）。パラメータファイルの各行は `EDITSAVEFILE`、`NAVFILE`、`SVPFILE`、`ROLLBIAS`、`TIDEFILE` などのコマンドです。パラメータファイルは `mbset` で作成・変更するほか、`mbclean`、`mbareaclean`、`mbvoxelclean`、`mbbackangle`、`mbsvplist`、`mbgpstide` など補助ファイルを作成するプログラムによっても変更されます。パラメータファイルがない場合、`mbprocess` は標準の名前の航法ファイルや編集保存ファイルを探して、妥当な処理内容を推定します。

適用できる処理には次のものがあります。

- 編集保存ファイル（`.esf`）による水深編集（ビームフラグ）
- 編集済み航法（`.nve`）、`mbnavadjust` による調整済み航法（`.na0`、`.na1` など）、別ファイルの姿勢・ソナー深度のマージ
- 音速プロファイル（`.svp`）を用いたレイトレーシングによる水深の再計算、または補正済み／未補正水深間の変換
- ロール・ピッチ・ヘディングのバイアス、喫水、ヒーブ、レバーアーム補正、ビームごとの静的オフセット
- 潮汐ファイル（`mbotps` や `mbgpstide` で作成したものなど）による潮汐補正
- ビーム番号、アクロストラック距離、速度によるデータカット
- `mbbackangle` で作成したグレージング角テーブルによる振幅・サイドスキャン補正、一部のソナーでのサイドスキャン再計算
- メタデータ（船名、機関、航海、主任研究者など）の挿入

`-I` で指定する入力は、1 つのスワスファイルまたはデータリストです。データリストは再帰的に読み込まれ、含まれるすべてのスワスファイルが処理されます。`-I` を省略した場合、カレントディレクトリに `datalist.mb-1` があればそれを使用します。出力ファイル名はフォーマット ID に従い、`root.mbXX` は `rootp.mbXX` になります（例: `mydata.mb71` は `mydatap.mb71`）。`.mbXX` の拡張子を持たない名前には `p.mbXX` が付加されます。出力ファイルは入力ファイルと同じフォルダに書き込まれます。各出力ファイルについて、補助ファイル `.inf`、`.fbt`、`.fnv` も生成されます。

既定では、出力ファイルが存在しない場合、または入力ファイル、パラメータファイル、そこで参照されている補助ファイル（航法、編集保存、SVP ファイルなど）より古い場合にのみ処理します。すべてのファイルを強制的に処理するには `-P` を使います。`-C` を指定すると、データリスト内の複数のファイルを並列スレッドで処理します。

Kongsberg kmall データ（フォーマット 261）では、`mbpreprocess` が書き込んだ #XMT データグラムの往復時間と角度から水深を再計算するため、先に前処理を行っておく必要があります。

## 主なオプション

- `-I<file>` / `--input=<file>` — 処理するスワスファイルまたはデータリスト。既定値: カレントディレクトリに存在する場合は `datalist.mb-1`。
- `-C<n>` / `--threads=<n>` — 並列に処理するファイル数。既定値: 1。CPU コア数が上限です。
- `-F<format>` / `--format=<format>` — 入力の MBIO フォーマット ID。通常はパラメータファイルから取得するか、`.mbXX` 拡張子から判別します。入力が単一ファイルの場合のみ有効です。
- `-O<file>` / `--output=<file>` — 単一入力ファイルの出力ファイル名。既定の `rootp.mbXX` を上書きします。入力がデータリストの場合は無視されます。
- `-P` / `--force` — 出力が最新であってもすべてのファイルを処理します。
- `-T` / `--test` — テストモード。処理対象となるファイルを報告するだけで、実際の処理は行いません。
- `-S` / `--print-status` — 各ファイルの状態（最新、要更新、ロック中）と、判定に使用した更新日時を表示します。
- `-N` / `--strip-comments` — 入力のコメントレコードをコピーせず、処理パラメータを記述したコメントも埋め込みません。
- `-V` / `--verbose` — 処理パラメータとレコード数を表示します。
- `-H` / `--help` — 簡単なヘルプを表示して終了します。

## 使用例

カレントディレクトリのデータリストに含まれるファイルのうち、更新が必要なものだけを処理します。

    mbprocess -Idatalist.mb-1

`mbset` で 1 つの Kongsberg ファイルに SVP ファイル、ロールバイアス、一定の喫水を設定し、進行状況を表示しながら処理します。

    mbset -I0051_20010829_223755.mb57 -PSVPFILE:0051_20010829_223755.mb57.svp -PROLLBIAS:0.5 -PDRAFT:1.95
    mbprocess -I0051_20010829_223755.mb57 -V

処理を行わずに、処理が必要なファイルを確認します。

    mbprocess -Idatalist.mb-1 -T -S

4 スレッドで調査のすべてのファイルを再処理します。

    mbprocess -Idatalist.mb-1 -P -C4

## 注意

- 処理済みファイルを後で使うには、それらを参照するデータリストを作成します。たとえば `mbdatalist -Idatalist.mb-1 -Z` を実行するか、データリストに `$PROCESSED` を追加します。
- 処理が元のファイルを直接書き換えることはありません。生ファイルはそのまま残るため、別のパラメータでいつでも再処理できます。
- 他のプログラム（エディタなど）がロックしているファイルはスキップされ、報告されます。
- データリストとパラメータファイルはファイル名をスペースで区切って保存するため、調査フォルダ名やファイル名にはスペースを含めないでください。
- パラメータファイルのコマンドの完全な一覧は、マニュアルページ mbprocess(1) と mbset(1) にあります。
