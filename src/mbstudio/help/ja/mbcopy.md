# mbcopy — フォーマット変換・範囲指定・平均化を伴うスワスファイルのコピー

`mbcopy` はスワスソナーデータファイルを新しいファイルにコピーします。必要に応じて別の MBIO フォーマットへの変換、時間範囲や地理的範囲での切り出し、ピングの平均化、別ファイルからの水深のマージを行えます。フォーマット変換や測線の一部の抽出に使う汎用ツールです。

## 書式

    mbcopy
        --bathymetry-only {-D}
        --begin-time=yr/mo/da/hr/mn/sc {-Byr/mo/da/hr/mn/sc}
        --bounds=west/east/south/north {-Rwest/east/south/north}
        --comment-file=commentfile {-Ccommentfile}
        --end-time=yr/mo/da/hr/mn/sc {-Eyr/mo/da/hr/mn/sc}
        --format=iformat/oformat/mformat {-Fiformat/oformat/mformat}
        --help {-H}
        --input=infile {-Iinfile}
        --lonflip=lonflip {-Llonflip}
        --merge-file=mergefile {-Mmergefile}
        --output=outfile {-Ooutfile}
        --ping-average=pings {-Ppings}
        --sleep-factor=sleep_factor {-Qsleep_factor}
        --speed-minimum=speed {-Sspeed}
        --strip-comments {-N}
        --time-gap=timegap {-Ttimegap}
        --verbose {-V}

## 説明

`mbcopy` は 1 つのスワスファイル（データリストではない）を読み込み、1 つの出力ファイルを書き出します。入力と出力のフォーマットが同じソナーシステムのものであれば、データストリーム全体がコピーされます。異なるシステムのフォーマットの場合は、時刻、航法、ビームの値（水深、振幅、サイドスキャン）のみが引き継がれます。ピングの平均化を行う場合も同様に部分的なコピーになります。

データは時間範囲（`-B`、`-E`）、地理的範囲（`-R`）、最低船速（`-S`）で制限できます。開始時刻が終了時刻より後の場合は、逆に 2 つの時刻の間のデータが除外されます。

`-M` を指定すると、水深とビームフラグをマージファイルから取得し、入力ファイルの他のすべてのデータと合わせて書き出します。同じ生データから得られた 2 つの処理系統を統合するもので、たとえば他のソフトウェアで出力した補正済み水深と、元の姿勢・後方散乱レコードを組み合わせることができます。

既定では、`mbcopy` は実行内容を記録したコメントレコードを追加し、入力のコメントも引き継ぎます。`-I` を指定しない場合は標準入力から読み込み、`-O` を指定しない場合は標準出力に書き出します。

## 主なオプション

- `-I<file>` / `--input=<file>` — 入力スワスファイル。既定値: 標準入力。
- `-O<file>` / `--output=<file>` — 出力スワスファイル。既定値: 標準出力。
- `-F<iformat>[/<oformat>[/<mformat>]]` / `--format=...` — 入力、出力、マージファイルのフォーマット ID。入力フォーマットのみを指定した場合、出力フォーマットも同じになります。省略すると、入力フォーマットは入力ファイル名（たとえば `.mb58`）から、マージフォーマットはマージファイル名から判別されます。
- `-B<yr/mo/da/hr/mn/sc>` / `--begin-time=...` — 時間範囲の開始。既定値: 1962/2/21/10/30/0。
- `-E<yr/mo/da/hr/mn/sc>` / `--end-time=...` — 時間範囲の終了。既定値: 2062/2/21/10/30/0。
- `-R<west/east/south/north>` / `--bounds=...` — この経度・緯度範囲内のデータのみをコピーします。
- `-P<pings>` / `--ping-average=<pings>` — このピング数を平均して 1 つの出力ピングにします。`0` を指定すると、アロングトラック間隔がアクロストラックのビーム間隔と等しくなるよう自動的に決定します。既定値: 1（平均化なし）。
- `-S<speed>` / `--speed-minimum=<speed>` — 船速がこの値（km/h）未満のピングをスキップします。既定値: 0。
- `-T<timegap>` / `--time-gap=<timegap>` — データの欠落とみなすピング間の時間間隔（分）。既定値: 1。
- `-M<mergefile>` / `--merge-file=<mergefile>` — このファイルから水深とビームフラグを取得します。
- `-D` / `--bathymetry-only` — 水深のみを書き出します（振幅とサイドスキャンは書き出しません）。出力フォーマット 71 でのみ有効です。高速水深（`.fbt`）ファイルはこの方法で作成されます。
- `-N` / `--strip-comments` — `mbcopy` のコメントを書き出さず、入力のコメントも削除します。2 回指定（`-N -N`）すると、さらに水深、航法、ヘディング、姿勢のレコードのみを通過させます（これらのレコードを区別するフォーマットの場合）。
- `-C<commentfile>` / `--comment-file=<commentfile>` — テキストファイルの各行をコメントとして出力の先頭に挿入します。
- `-L<lonflip>` / `--lonflip=<lonflip>` — 経度の範囲。`-1` で -360〜0、`0` で -180〜180、`1` で 0〜360。
- `-Q<sleep_factor>` / `--sleep-factor=<sleep_factor>` — 各レコードの前に、ピング間隔にこの係数を掛けた時間だけ待機し、収録システムを模擬します。
- `-V` / `--verbose` — レコード数とメッセージを表示します。

## 使用例

生の Hydrosweep ファイル（フォーマット 21）をフォーマット 24 に変換し、西経 145 度〜140 度、南緯 10 度〜5 度のデータのみを残します。

    mbcopy -F21/24 -R-145/-140/-10/-5 -Ihs_raw -Ohs_binary

Kongsberg ファイルから 1 時間分を同じフォーマットの新しいファイルに切り出します。

    mbcopy -I0001_20250101_000000.mb58 -B2025/01/01/10/00/00 -E2025/01/01/11/00/00 -Oline1_part.mb58

生の Simrad データ（フォーマット 56、フォーマット 57 として出力）と GSF ファイル（フォーマット 121）の補正済み水深を組み合わせます。

    mbcopy -F56/57/121 -I0015_20040212_052714_raw.all -M20040212_052714.gsf -O20040212_052714.mb57

フォーマット 71 で水深のみのコンパクトなコピーを書き出します。

    mbcopy -F58/71 -D -I0001_20250101_000000.mb58 -O0001_20250101_000000.mb71

## 注意

- 必ず `-O` を指定してください。スワスデータはバイナリなので、コンソールに出力してはいけません。
- 入力と出力のフォーマットの組み合わせによっては意味をなさないものがあります。異なるソナーシステム間で変換すると、システム固有のレコードは失われます。
- スペースを含むファイル名は引用符で囲んでください。例: `-I"D:\Survey 2025\line1.mb58"`。
