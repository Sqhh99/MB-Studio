# mbsvplist — スワスデータ内の音速プロファイルを一覧表示

`mbsvplist` は、スワスソナーのデータファイル内に記録されている水中の音速プロファイル（SVP）を取り出します。前処理の後に、調査データにどの SVP が含まれているかを確認したり、SVP を `.svp` ファイルとして保存したり、各ファイルの最初の SVP を `mbprocess` による水深再計算に使用するよう設定したりするときに使います。ソナーがビームフォーミングに使用した表層音速（SSV）を一覧表示することもできます。

## 書式

    mbsvplist
        --bounds=west/east/south/north {-Rwest/east/south/north}
        --counts {-C}
        --duplicates {-D}
        --format=format_id {-Fformat_id}
        --help {-H}
        --input=file {-Ifile}
        --min-num-pairs=min_num_pairs {-Nmin_num_pairs}
        --mode=mode {-Mmode}
        --output {-O}
        --process {-P}
        --source=source {-Asource}
        --ssv {-S}
        --table {-T}
        --verbose {-V}
        --zero-depth {-Z}

## 説明

スワス水深は、生のビーム角と往復時間から、水中音速のモデルを使ったレイトレーシングによって計算されます。多くのデータフォーマットはデータストリーム内に SVP を保存でき、収録システムが計算に使用したプロファイルが含まれていることもよくあります。`mbsvplist` は 1 つのスワスファイル、またはデータリストが参照するすべてのファイル（既定の入力は `datalist.mb-1`）を読み込み、それらのプロファイルを出力します。

既定では、SVP はテキストとして標準出力に書き出されます。出力されるのは各ファイルの最初の SVP と、直前の SVP と異なる SVP だけで、重複は省略されます（`-M` と `-D` を参照）。`-O` を指定すると、各 SVP は `<swathfile>_NNN.svp` という名前の個別のファイルに書き出されます（NNN はそのファイル内での SVP 番号で、`000` から始まります）。これらのファイルの先頭には、プロファイルの時刻と位置を記した `## MB-SVP` 形式のヘッダーが付き、`mbsvpselect` はこの情報を使って各スワスファイルに最適な SVP を選択します。

`-P` は `-O` と同じ出力を行い、さらに `mbprocess` のパラメータファイル（`<swathfile>.par`）を更新して、各ファイルについて最初に書き出された SVP が `mbprocess` での水深再計算に使われるようにします。

`-T` は完全なプロファイルの代わりに簡潔な CSV 表（SVP 番号、時刻、経度、緯度、深度-音速ペア数）を出力し、`-C` は各ファイル内の固有 SVP の数だけを出力します。`-S` はビームフォーミングに使われた表層音速をソナー深度と組にして、通常は 1 ピングにつき 1 つずつ出力します。`-R` を併用すると、SSV の出力を経度・緯度の範囲内に限定できます。

## 主なオプション

- `-Ifile` — 入力スワスファイルまたはデータリスト。既定値: `datalist.mb-1`。
- `-Fformat_id` — 入力の MBIO フォーマット ID。通常はファイル名の拡張子から推定されます。負の値は入力がデータリストであることを意味します。
- `-O` — 各 SVP を標準出力ではなく個別の `<swathfile>_NNN.svp` ファイルに書き出します。
- `-P` — `-O` と同様に出力し、さらに各ファイルの最初の SVP を `mbprocess` 用にパラメータファイルへ設定します。
- `-Mmode` — SVP の出力モード: `0`（既定）各ファイルの最初の SVP と直前と異なるすべての SVP、`1` データリスト内の複数ファイルにまたがっても固有 SVP の最初の 1 回だけ、`2` 重複を含むすべての SVP。
- `-D` — 重複する SVP も出力します（`-M2` と同じ）。
- `-Asource` — SVP の取得元とするレコード種別: `S` は音速プロファイルレコード（既定）、`C` は CTD レコード。
- `-Nmin_num_pairs` — 深度-音速ペアがこの数より少ない SVP を無視します（1 つの音速値が 1 点だけの「SVP」として保存されている場合に便利です）。既定値: `0`。
- `-Z` — 出力前に各 SVP の最初の深度を 0 に置き換えます（海面から始まらないプロファイルは `mbprocess` で問題を起こすため、その対策です）。
- `-T` — 完全なプロファイルの代わりに、各 SVP の概要を CSV 表で出力します。
- `-C` — 各ファイル内の固有 SVP の数だけを出力します。
- `-S` — SVP の代わりに、ピングごとの表層音速（SSV）とソナー深度を出力します。
- `-Rwest/east/south/north` — `-S` と併用し、この範囲内の SSV 値だけを出力します。既定: すべて。
- `-V` — 詳細表示（進行状況とレコード数をエラー出力に表示）。
- `-H` — ヘルプを表示して終了します。

## 使用例

データリスト内の全ファイルに含まれる SVP を画面に一覧表示します。

    mbsvplist -I datalist.mb-1 -V

SVP を `.svp` ファイルに書き出し、各ファイルの最初の SVP を水深再計算用に設定してから処理します。

    mbsvplist -I datalist.mb-1 -P -V
    mbprocess -I datalist.mb-1

全 SVP の概要表（時刻、位置、点数）を CSV ファイルに保存します。

    mbsvplist -I datalist.mb-1 -T > svp_table.csv

1 つの Kongsberg ファイルについて、指定範囲内の表層音速を出力します。

    mbsvplist -I survey\0001_20250101_000000.all -S -R139.5/139.8/35.2/35.5 > ssv.txt

## 注意

- `-O` と `-P` で作成される `.svp` ファイルは、カレントディレクトリではなくスワスデータファイルと同じ場所（データリストに記載されたパス）に書き出されます。
- `-P` は `.par` ファイルを変更します。新しい SVP を適用するには、その後で `mbprocess` を実行してください。
- `-S` は別の出力モードです。`-O`、`-P`、`-C`、`-T` と組み合わせないでください。
- 空白を含むファイル名は `-I "my survey\datalist.mb-1"` のように引用符で囲んでください。
