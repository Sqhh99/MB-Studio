# mbrolltimelag — ロールと海底傾斜の相関によるロール時間遅れの推定

`mbrolltimelag` は、スワス水深データのピング時刻と、水深計算に使われたロールデータとの間の時間遅れ（時刻のずれ）を推定します。ロールの時系列と見かけの横断方向海底傾斜との相互相関を計算し、ゼロ以外の遅れに明瞭な相関ピークがあれば、姿勢データのタイミングに問題があることを示します。外側スワスに船体のロールに合わせた「波打ち」が見られるときの品質管理に使用します。

## 書式

    mbrolltimelag
        --correlation-threshold=value {-Cvalue}
        --format=format_id {-Fformat_id}
        --help {-H}
        --input=swathdata {-Iswathdata}
        --lag-range=nlag/lagmin/lagmax {-Tnlag/lagmin/lagmax}
        --nav-channel=navchannel {-Snavchannel}
        --npings=nping {-Nnping}
        --output=outputname {-Ooutputname}
        --roll-source=rollsource {-Krollsource}
        --verbose {-V}

## 説明

ロールが誤った時刻で適用されると、各横断プロファイルがロール誤差の分だけ傾き、片舷が浅く反対舷が深くなります。`mbrolltimelag` は見かけの横断方向海底傾斜から適用済みのロールを差し引き、その結果とロール信号との相互相関を、一連の時間遅れについて計算します。海底がほぼ平坦であれば傾斜信号はロール誤差が支配的となり、相互相関は実際の時間遅れで明瞭なピークを示します。

入力は単一のスワスファイルまたはデータリストです。まず入力全体からロールの時系列を `mbnavlist` で取り出し、各ピングの傾斜を `mblist` で取り出します（どちらも自動的に実行されます）。その後、`nping` ピングごとのブロックに分けて処理し、各ブロックについて `lagmin` から `lagmax` 秒まで等間隔の `nlag` 個の遅れで相互相関関数を計算します。相関ピークの値が `-C` で設定したしきい値を超えた場合、そのピークの遅れを推定値として採用します。

出力ファイル名のルートは、既定では入力名から MB-System の拡張子を除いたものです（`datalist.mb-1` ならルートは `datalist`）。次のファイルが書き出されます。

- `root_timelagest.txt` — 採用された推定値: 時刻（エポック秒）と時間遅れ（秒）。
- `root_timelaghist.txt` — 採用されたすべての時間遅れ（ヒストグラム用）。
- `root_timelagmodel.txt` — ヒストグラムのピークが明確な入力ファイルごとに 1 つの時間遅れ（時刻と遅れ）。
- `root_xcorr.txt` — すべての相互相関関数（入力がデータリストの場合のみ）。

さらに各スワスファイルについて、そのファイル名に基づく `_xcorr.txt` と `_timelaghist.txt` ファイルがスワスファイルと同じ場所に書き出されます。明確で一貫した時間遅れが得られた場合は、たとえば `mbpreprocess` の時間遅延（time latency）オプションで補正できます。

## 主なオプション

- `-Iswathdata` — 入力スワスファイルまたはデータリスト（長形式 `--input`）。既定値: `datalist.mb-1`。
- `-Fformat_id` — 入力の MB-System フォーマット ID（`--format`）。負の値はデータリストを意味します。既定値: ファイル名の拡張子（例: `.mb88`、`.mb-1`）から判定。
- `-Nnping` — 1 つの相互相関推定に使うピング数（`--npings`）。既定値: 100。
- `-Tnlag/lagmin/lagmax` — 時間遅れの個数と範囲（秒）（`--lag-range`）。既定値: `41/-2.0/2.0`（0.1 秒間隔）。
- `-Cvalue` — 推定値として採用する相関係数ピークの最小値（`--correlation-threshold`）。既定値: 0.9。
- `-Krollsource` — この種別のデータレコードからロールを取り出します（`--roll-source`）。例: 18 は非同期姿勢レコード、1 は測深レコード。既定では測深データレコードから取り出します。
- `-Snavchannel` — 代わりに非同期航法レコードの航法チャンネル `navchannel`（1、2、3）からロールを取り出します（`--nav-channel`）。ファイルに含まれるレコード種別は `mbinfo -N` で確認できます。
- `-Ooutputname` — 出力ファイル名のルート（`--output`）。
- `-V` — 詳細表示。パラメータと各ブロックの相関ピークを表示します（`--verbose`）。
- `-H` — 簡単な説明と使用法を表示して終了します（`--help`）。

## 使用例

データリスト中の全ファイルについて、-2 秒から 2 秒まで 0.1 秒間隔で、航法チャンネル 2 のロールを使ってロール時間遅れを推定します。

    mbrolltimelag -Idatalistp.mb-1 -T41/-2.0/2.0 -S2 -V

Reson 7k の単一ファイルを、非同期姿勢レコード、1 推定あたり 200 ピング、-0.5 秒から 0.5 秒の細かい遅れ範囲、出力ルート `line0001` で調べます。

    mbrolltimelag -I0001_20250101_000000.mb88 -K18 -N200 -T51/-0.5/0.5 -Oline0001

## 注意

- Windows では、通常 `mbm_xyplot` と `mbm_histplot` マクロで作成されるプロットは省略されます（マクロが利用できないため）。テキストの結果ファイルは書き出されるので、表計算ソフトやグラフ作成ツールで描画できます。
- `mbnavlist` と `mblist` が必要です。これらは同じ `bin` フォルダにインストールされています。
- 結果が意味を持つのは、海底がほぼ平坦でデータの被覆が良好な場合です。遅れの範囲は予想される遅れより十分に広く取ってください。
- 負の値はオプションに続けて書いてください（`-T41/-2.0/2.0`）。別のオプションと誤認されるのを防げます。

## 関連項目
