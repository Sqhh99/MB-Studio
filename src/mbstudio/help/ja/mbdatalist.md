# mbdatalist — データリストの解析と補助ファイルの作成

`mbdatalist` はデータリスト（スワスファイルとそのフォーマット ID の一覧。ほかのデータリストを参照することもできます）を読み込み、見つかったスワスファイルをフォーマット ID とグリッド重みとともに出力します。グリッド作成や作図を高速化する ".inf"、".fbt"、".fnv" 補助ファイルの作成、処理状況や問題の確認、残ったままの処理ロックの解除にも使われる標準的なツールです。

## 書式

    mbdatalist
        [
        --verbose {-V}
        --help {-H}
        --copy {-C}
        --report {-D}
        --format=format_id {-Fformat_id}
        --input=file {-Ifile}
        --make-ancillary {-N}
        --update-ancillary {-O}
        --processed {-P}
        --problem {-Q}
        --bounds=w/e/s/n {-Rw/e/s/n}
        --status
        --raw {-U}
        --unlock {-Y}
        --datalistp {-Z}

## 説明

データリストは、各行にファイル名、MBIO フォーマット ID、および省略可能なグリッド重みを書いたテキストファイルです。例: `0001_20250101_000000.mb58 58`、`survey2\datalist.mb-1 -1 10.0`。データリスト自体のフォーマット ID は -1 なので、データリストは入れ子にできます。`mbdatalist` は構造全体をたどり、スワスファイルごとにパス、フォーマット ID、重み（既定値 1.0）を 1 行で出力します。データリストではなくスワスファイルを指定した場合は、そのファイルだけが出力されます。

`mbprocess` は「処理済み」ファイルを作成します（たとえば `line1.mb58` から `line1p.mb58`）。データリストに `$PROCESSED` タグがある場合、または `-P` を指定した場合は、処理済みファイルが存在すればその名前が出力されます。`$RAW` または `-U` では生データのファイルだけが出力されます。`-Z` は `$PROCESSED` と入力への参照を含む便利なデータリスト `datalistp.mb-1`（`datalist.mb-1` から作成）を作り、グリッド作成プログラムが処理済みデータを読むようにします。

`-N` はすべてのスワスファイルについて補助ファイルを作成します: ".inf" 統計（`mbinfo` で作成）、".fbt" 高速水深ファイル（`mbcopy` でフォーマット 71 として作成）、".fnv" 高速航法ファイル（`mblist` で作成）。`-O` は、補助ファイルがない場合やデータファイルより古い場合にだけ作成します。`mbgrid`、`mbmosaic`、`gmt mbswath` などはこれらのファイルを使って対象範囲外のデータを読み飛ばし、高速に読み込みます。

`-R` は ".inf" の範囲が指定範囲と重なるファイルだけを出力します（".inf" ファイルのないファイルは常に出力されます）。これにより `mbgrid` がどのファイルを使うかが分かります。`-Q` は各ファイルの `mbprocess` パラメータファイルが参照するファイル（編集保存ファイル、航法、潮汐、音速プロファイル）が欠けていないかを確認し、".inf" ファイルに記録されたデータの問題を表示します。`-S` は各ファイルが最新か再処理が必要か、ロックされているかを表示します。`-Y` は中断した `mbprocess` が残した処理ロック（".lck" ファイル）を削除します。`-D` はデータリストファイルそのものを再帰の階層レベルとともに一覧表示します。

## 主なオプション

- `-Ifile` (`--input=file`) — 入力データリストまたはスワスファイル。既定値: datalist.mb-1。
- `-Fformat_id` (`--format=format_id`) — 入力のフォーマット ID。データリストは -1。既定値: ファイル名の接尾辞から推定。
- `-N` (`--make-ancilliary`) — すべてのスワスファイルの ".inf"、".fbt"、".fnv" ファイルを作成（上書き）します。
- `-O` (`--update-ancilliary`) — 補助ファイルがないか古い場合にだけ作成します。
- `-P` (`--processed`) — 処理済みファイルが存在する場合はその名前を出力します。
- `-U` (`--raw`) — 生（未処理）ファイルの名前だけを出力します。
- `-Z` (`--datalistp`) — 入力のルートに "p.mb-1" を付けた名前（既定では datalistp.mb-1）で、`$PROCESSED` を設定して入力を参照するデータリストを書き出し、終了します。
- `-Rw/e/s/n` (`--bounds=w/e/s/n`) — ".inf" ファイルから判断して、この範囲内にデータがあるファイルだけを出力します。
- `-Q` (`--problem`) — 欠けている処理用ファイルとデータの問題を表示します。
- `-S` (`--status`) — 処理状況とロックを表示します。
- `-Y` (`--unlock`) — 出力対象のファイルの処理ロックを解除します。
- `-D` (`--report`) — スワスファイルの代わりに、再帰構造内のデータリストファイルを一覧表示します。
- `-C` (`--copy`) — 一覧のスワスファイルとその補助ファイルをカレントディレクトリにコピーし、そこに datalist.mb-1 を作成します。
- `-V` (`--verbose`), `-H` (`--help`) — 詳細メッセージ表示、使い方を表示して終了。

## 使用例

カレントディレクトリのデータリストが参照するすべてのスワスファイルを一覧表示します。

    mbdatalist

調査全体について、ないか古い ".inf"、".fbt"、".fnv" ファイルを作成します。

    mbdatalist -I datalist.mb-1 -O

後続のプログラムが処理済みファイルを使うように datalistp.mb-1 を作成します。

    mbdatalist -I datalist.mb-1 -Z

処理済みファイルがあればそれを使い、指定範囲内にデータを含むファイルを表示します。

    mbdatalist -I datalist.mb-1 -P -R140.5/141.0/35.0/35.4

## 注意

- このバージョンでは `-N` と `-O` の長い形式の綴りは `--make-ancilliary` と `--update-ancilliary` です。プログラムの使い方表示にある `--make-ancillary` と `--update-ancillary` は受け付けられません。短い形式 `-N` と `-O` は常に使えます。
- データリスト内のパスはデータリストのあるフォルダーからの相対パスです。コマンドラインでは空白を含むパスを引用符で囲んでください。
- `-N` と `-O` はファイルごとに `mbinfo`、`mbcopy`、`mblist` を実行するため、大きな調査では時間がかかります。
- `-C` のコピー機能は内部で Unix の `cp` コマンドを使うため、通常の Windows コマンドプロンプトでは動作しない場合があります。その場合はエクスプローラーや `copy` でファイルをコピーしてください。
