# mbmakedatalist — ディレクトリ内のスワスファイルのデータリストを作成

`mbmakedatalist` はディレクトリ内でスワスデータとして認識できるファイルを探し、各ファイルとそのフォーマット ID を記載した MB-System のデータリスト（既定は `datalist.mb-1`）を書き出します。新しい調査データの処理を準備するときに最初に実行するのが一般的で、他の多くの MB-System プログラムはこのデータリストを入力として使います。

## 書式

    mbmakedatalist [-B size|--min-size=size]
                   [-F format|--format=format]
                   [-I directory|--input=directory]
                   [-L|--skip-latest]
                   [-O datalist|--output=datalist]
                   [-P|--ignore-processed]
                   [-S suffix|--suffix=suffix]
                   [-T|--no-time-sort]
                   [-H|--help] [-V|--verbose]

## 説明

データリストは、1 行に 1 つのスワスファイルとその MBIO フォーマット ID を記したテキストファイルで、他のデータリストを参照することもできます。`mbmakedatalist` はこれを自動的に作成します。対象ディレクトリ（`-I` を指定しない場合はカレントディレクトリ）内のすべてのファイルについて、フォーマット 88 の `.mb88` や Kongsberg 独自の拡張子 `.all`、`.kmall` などの MB-System のファイル命名規則に合うかを調べ、認識できたファイルをその名前から推定したフォーマット ID とともに追加します。認識できないファイル、ディレクトリ、`-B` のしきい値より小さいファイルは除外されます。ファイルはアルファベット順に並びます。

通常は `-S` で対象ファイルの拡張子を指定するのが最善です。これにより、たまたま命名規則に合う無関係なファイルが含まれるのを防げます。`-S` を指定した場合、`-P` で処理済みファイル（拡張子の直前に文字 `p` が付いたもの。例: `mbprocess` が作成する `0001p.mb88`）を除外できるため、生データと処理済みデータが混在するディレクトリでも生ファイルだけのデータリストを作成できます。`-F` を使うと、推定する代わりにすべてのファイルに同じフォーマット ID を割り当てます。

Kongsberg のファイル名は、収録を再開するたびに 0001 から振り直されるライン番号で始まるため、アルファベット順が時刻順になるとは限りません。`-S` で指定した拡張子が `.all`、`.ALL`、`.kmall`、`.KMALL`、`.mb56`、`.mb57`、`.mb58`、`.mb59`、`.mb261` のいずれかの場合、ファイルは名前に含まれる日付と時刻（`NNNN_YYYYMMDD_HHMMSS...`）で並べ替えられます。`-T` でこれを無効にできます。`9999.all`、`9999.ALL`、`9999.kmall`、`9999.KMALL` という名前の Kongsberg の不要ファイルは無視されます。

データリストはカレントディレクトリ（または `-O` で指定したパス）に書き出されます。スワスファイルが 1 つも見つからない場合、データリストは作成されません。

## 主なオプション

- `-S suffix` — この拡張子で終わるファイルだけを対象にします（例: `.all`、`.kmall`、`.mb88`）。大文字と小文字は区別されます。
- `-I directory` — 調べるディレクトリ。既定: カレントディレクトリ。
- `-O datalist` — 出力するデータリストの名前。既定値: `datalist.mb-1`。
- `-P` — `-S` と併用し、処理済みファイル（拡張子の前に `p` が付くもの）を除外します。
- `-F format` — 名前から推定する代わりに、すべてのファイルにこのフォーマット ID を割り当てます。
- `-B size` — size キロバイトより小さいファイルを無視します。
- `-L` — リストの最後のファイルを除外します（例: 収録中でまだ書き込みが続いているファイル）。
- `-T` — Kongsberg ファイルを時刻順に並べ替えません。
- `-V` — 確認内容と追加した各ファイルを表示します。
- `-H` — ヘルプを表示して終了します。

すべてのオプションには、書式に示した長い形式もあります（例: `--suffix=.all`）。

## 使用例

カレントディレクトリ内の認識可能なすべてのスワスファイルから `datalist.mb-1` を作成し、追加したファイルを表示します。

    mbmakedatalist -V

サブディレクトリ `rawdata` 内の Kongsberg の生 `.all` ファイルだけを、収録中のファイルを除いて時刻順に `kongsberg.mb-1` に記載します。

    mbmakedatalist -I rawdata -S .all -P -L -O kongsberg.mb-1

同じ処理を長い形式のオプションで指定します。

    mbmakedatalist --input=rawdata --suffix=.all --ignore-processed --skip-latest --output=kongsberg.mb-1

100 キロバイトより大きい `.kmall` ファイルのデータリストを作成します。

    mbmakedatalist -S .kmall -B 100

## 注意

- `-I` を使うと、各エントリはカレントディレクトリからの相対パス `directory/filename` として書き出されます。後続の MB-System プログラムは同じディレクトリから実行するか、`-I` に絶対パスを指定してください。
- 拡張子の照合は大文字と小文字を区別します。`-S .all` は `0001_20250101_000000.ALL` に一致しません。
- Kongsberg の時刻順並べ替えが有効な場合、名前に `NNNN_YYYYMMDD_HHMMSS` の形式を含まないファイルはリストから外されます。ファイル名の形式が異なる場合は `-T` を使ってください。
- 結果は `mbdatalist -I datalist.mb-1` または `mbinfo -I datalist.mb-1` で確認できます。
