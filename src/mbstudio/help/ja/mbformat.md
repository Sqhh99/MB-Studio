# mbformat — MB-System のスワスデータフォーマットを識別・説明

`mbformat` は MBIO ライブラリが対応するスワスデータフォーマットについて説明を表示します。対応フォーマットの一覧表示、特定のフォーマット ID の説明、あるいはファイル名から MB-System が想定するフォーマット ID の判定ができます。`-F` オプションやデータリストの各行に書くフォーマット ID を調べるときに使います。

## 書式

    mbformat
        --format=format_id {-Fformat_id}
        --help {-H}
        --html {-W}
        --input=file {-Ifile}
        --list-ids {-L}
        --list-root {-K}
        --verbose {-V}

## 説明

オプションなしで実行すると、対応するすべてのフォーマットについて ID、名前、簡単な説明、属性（ソナー、ビーム数、データ種別、ファイル形式）を一覧表示します。`-F` を指定すると、そのフォーマット ID の説明を表示します。

`-I` を指定すると、MB-System に組み込まれたファイル名の接頭辞・接尾辞の規則（".mb58"、".all"、".s7k"、".xtf" など）に照らしてファイル名を調べ、推定されたフォーマット ID を表示します。また、ファイル名から認識された接尾辞や接頭辞を除いたファイルの「ルート」も求めます。判定は主にファイル名で行われますが、一部の接尾辞（".all" など）ではフォーマットの変種を区別するためにファイルの先頭も読み込むので、ファイルが存在している必要があります。

`-L` を指定すると出力はフォーマット ID の数値のみ（有効な ID が見つからなければ 0）になり、`-K` ではファイルのルートとフォーマット ID が出力されます。これらはスクリプトで便利です。`-W` はすべてのフォーマットの一覧を HTML ページとして出力します。

## 主なオプション

- `-Fformat_id` (`--format=format_id`) — このフォーマット ID の説明を表示します。`-F` も `-I` も指定しない場合はすべてのフォーマットを一覧表示します。
- `-Ifile` (`--input=file`) — このファイル名からフォーマット ID を推定します。
- `-L` (`--list-ids`) — フォーマット ID の数値のみを出力します（識別できなければ 0）。
- `-K` (`--list-root`) — ファイルのルートとフォーマット ID を出力します。
- `-W` (`--html`) — すべてのフォーマットの一覧を HTML で出力します。
- `-V` (`--verbose`) — プログラムのバージョンも表示します。
- `-H` (`--help`) — 簡単な説明と使い方を表示して終了します。

## 使用例

対応するすべてのフォーマットを一覧表示します。

    mbformat

フォーマット 58（Kongsberg 第 3 世代マルチビームのベンダーフォーマット、EM122/EM302/EM710 など）の説明を表示します。

    mbformat -F58

Kongsberg の ".all" ファイルに対して MB-System が想定するフォーマット ID を調べます。

    mbformat -I 0001_20250101_000000.all

ファイル名のルートとフォーマット ID だけを出力します。

    mbformat -K -I 0001_20250101_000000.mb58

フォーマット一覧を HTML ページとして保存します。

    mbformat -W > formats.html

## 注意

- ファイル名に認識できる接尾辞がない場合、`mbformat` はフォーマットを推定できないと報告します。その場合は他のプログラムで `-F` によりフォーマットを明示してください。
- フォーマット ID はデータリストでも使われます。各行にはファイル名とそのフォーマット ID を書きます。
