# mbgetesf — スワスファイルのビームフラグを編集保存ファイルに抽出

`mbgetesf` は、スワスデータファイルに保存されているビームフラグを読み取り、編集保存ファイル（`.esf`）として書き出します。これは `mbclean` や対話型エディタが作成するものと同じ種類のファイルです。あるバージョンのデータセット（編集済みのファイルや変換済みのファイルなど）で行った編集を、同じデータの別バージョンへ、編集し直すことなく移すために使用します。

## 書式

    mbgetesf
        --begin-time=yr/mo/da/hr/mn/sc {-Byr/mo/da/hr/mn/sc}
        --end-time=yr/mo/da/hr/mn/sc {-Eyr/mo/da/hr/mn/sc}
        --format=format_id {-Fformat_id}
        --help {-H}
        --input=infile {-Iinfile}
        --kluge=value {-Kvalue}
        --mode=value {-Mvalue}
        --output=esffile {-Oesffile}
        --verbose {-V}

## 説明

水深編集では不良ビームにフラグを立てます。通常、これらのフラグは編集保存ファイルに保存され、`mbprocess` によって生データに適用されます。しかし、フラグがデータファイルの中にしか存在しない場合もあります。たとえば元のデータストリームの一部しか保持しないフォーマットで編集したファイルや、他のソフトウェアで処理したデータなどです。`mbgetesf` はそのようなファイルのフラグを編集イベント（時刻、ビーム番号、操作）に変換し、編集保存ファイルに書き出します。

出力ファイル名を対象スワスファイル名に `.esf` を付けた名前にしておくと、`mbclean` が自動的に読み込んで出発点として使用します。編集を直接適用するには、`mbset`（`EDITSAVEMODE`、`EDITSAVEFILE`）で対象ファイルのパラメータファイルの編集適用を有効にし、`mbprocess` を実行します。

既定ではフラグ付きのビームのみが書き出されます（`-M1`）。モード 2 と 3 ではヌルビーム、または正常なビームを含むすべてのビームも書き出します。これは、以前の編集で元々正常だったビームをヌルにしたり、元々フラグ付きだったビームのフラグを解除したりした場合に役立ちます。モード 4〜6 では、記載されていないすべてのビームに暗黙の既定状態（正常、ヌル、またはフォーマットに応じて選択）を持つファイルを書き出します。これは `mbpreprocess` が「グローバル編集ファイル」（`.gef`）で使用する形式です。

プログラムは 1 つのスワスファイル（データリストではない）を読み込みます。入力ファイルを指定しない場合は標準入力から読み込み、出力ファイルを指定しない場合は編集イベントを標準出力に書き出します。

## 主なオプション

- `-I<file>` / `--input=<file>` — 読み込むスワスデータファイル。既定値: 標準入力。
- `-O<esffile>` / `--output=<esffile>` — 書き出す編集保存ファイル。既定値: 標準出力。
- `-F<format_id>` / `--format=<format_id>` — 入力の MBIO フォーマット ID。通常はファイル名から判別されます。
- `-M<mode>` / `--mode=<mode>` — 書き出すビーム。`1` フラグ付きビームのみ（既定）、`2` フラグ付きとヌルのビーム、`3` すべてのビーム。`4`、`5`、`6` は、記載されないビームをフォーマットに応じて正常またはヌル（`4`）、ヌル（`5`）、正常（`6`）とする暗黙既定の編集ファイルを書き出します。
- `-B<yr/mo/da/hr/mn/sc>` / `--begin-time=...` — 時間範囲の開始。既定値: 1962/2/21/10/30/0。
- `-E<yr/mo/da/hr/mn/sc>` / `--end-time=...` — 時間範囲の終了。既定値: 2062/2/21/10/30/0。
- `-K<value>` / `--kluge=<value>` — `1` を指定すると、HDCS フォーマット（フォーマット 151）の一部の EM300/EM3000 データに見られる 1 ビーム分のインデックスのずれを補正します。他のフォーマットには影響しません。既定値: 0。
- `-V` / `--verbose` — モードと書き出したビーム数を表示します。
- `-H` / `--help` — 簡単なヘルプを表示して終了します。

## 使用例

編集済みのフォーマット 22 のファイルからフラグを抽出し、対応するフォーマット 24 のファイルの名前で保存します。

    mbgetesf -F22 -Ihs_ew9103_143.mb22 -Ohs_ew9103_143.mb24.esf -V

フォーマット 24 のファイルで抽出した編集を有効にし、処理します。

    mbset -Ihs_ew9103_143.mb24 -PEDITSAVEMODE:1 -PEDITSAVEFILE:hs_ew9103_143.mb24.esf
    mbprocess -Ihs_ew9103_143.mb24

1 時間分のデータについて、すべてのビーム（正常、フラグ付き、ヌル）の編集イベントを書き出します。

    mbgetesf -Iedited_line.mb57 -M3 -B2025/01/01/10/00/00 -E2025/01/01/11/00/00 -Oraw_line.mb57.esf

## 注意

- 2 つのファイルには同じピングが含まれている必要があります。編集イベントは時刻とビーム番号で照合されます。
- 出力名と同じ名前の既存の編集保存ファイルは上書きされます。以前の編集を残したいファイルの `.esf` ファイルに上書きしないでください。
- 出力はバイナリファイルです。コンソールに表示させず、必ず `-O` を指定してください。
