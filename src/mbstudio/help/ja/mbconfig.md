# mbconfig — MB-System のバージョンとインストール設定を表示

`mbconfig` はインストールされている MB-System の情報を表示します。バージョン（複数の形式）、インストールプレフィックス、MB-System ライブラリを使うプログラムをビルドするためのコンパイラ・リンカフラグ、Levitus 音速データベースと OTPS 潮汐予測ソフトウェアの設定された場所を出力します。処理記録やバッチファイルなどで、インストールされている MB-System のバージョンを確認するときに使います。

## 書式

    mbconfig --verbose --help --prefix --cflags --libs
             --version --version-id --version-major --version-minor --version-archive
             --levitus --otps

## 説明

要求された各値は、他のテキストを付けずに 1 行ずつ標準出力に書き出されるため、出力を簡単に取り込めます。オプションを指定しない場合は、`--version` を指定したときと同様にバージョン文字列を表示します。

複数のオプションを組み合わせられます。値はコマンドラインでのオプションの順序に関係なく、常に決まった順序（プレフィックス、コンパイルフラグ、リンクフラグ、バージョン、バージョン ID、メジャー、マイナー、アーカイブバージョン、Levitus の場所、OTPS の場所）で表示されます。

`--verbose` を指定すると、各値の前に `#` で始まる説明行（例: `# MB-System version:`）が付き、プログラム名とバージョンが標準エラーにも書き出されます。

バージョン ID は新しいリリースほど必ず大きくなる整数で、version_id = 10000000 x major + 100000 x minor + archive です。例えばバージョン 5.5.2304 の ID は 50502304 です。スクリプトでバージョンを比較するのに便利です。

プレフィックス、フラグ、データの場所は MB-System のビルド時に固定された値です。ビルド時の設定を示すものであり、MB-Studio がインストールされたフォルダと一致するとは限りません（注意を参照）。

## 主なオプション

- `--version` — MB-System のバージョン文字列を表示します（オプションを指定しない場合の既定）。
- `--version-id` — バージョンを 1 つの整数で表示します（説明を参照）。
- `--version-major` — メジャーバージョン番号（3 つの数字の 1 番目）を表示します。
- `--version-minor` — マイナーバージョン番号（2 番目の数字）を表示します。
- `--version-archive` — アーカイブ（リビジョン）番号（3 番目の数字）を表示します。
- `--prefix` — ビルド時に設定されたインストールプレフィックスを表示します。
- `--cflags` — MB-System のヘッダーファイルの場所を示すコンパイラフラグを表示します。
- `--libs` — MB-System ライブラリのリンカフラグを表示します。
- `--levitus` — `mblevitus` が使う Levitus 年平均音速データベースの設定されたパスを表示します。
- `--otps` — `mbotps` が使う OTPS 潮汐予測ソフトウェアの設定された場所を表示します。
- `--verbose` — 各値の前に `#` で始まる説明行を付けます。2 回以上指定するとデバッグ出力になります。
- `--help` — 短い説明と使用法を標準エラーに表示します。

## 使用例

インストールされている MB-System のバージョンを表示します。

    mbconfig

説明ラベル付きでバージョンをバージョン ID と一緒に表示します。

    mbconfig --version --version-id --verbose

処理記録の一部として、バージョンをテキストファイルに保存します。

    mbconfig --version > mbsystem_version.txt

## 注意

- 受け付けるのは長いオプション（`--` で始まるもの）だけです。不明なオプションを指定すると使用法を表示してエラー終了します。
- `--prefix`、`--levitus`、`--otps` はビルド時に固定されたパスを表示します。Windows 版の `mblevitus` は、自身のプログラムフォルダからの相対位置（インストールフォルダの `share\mbsystem`）または環境変数 `MBSYSTEM_SHAREDIR` で指定したフォルダからデータベースを探すため、これらのパスは実際に使われるファイルと異なる場合があります。
- `--cflags` と `--libs` は、MB-System ライブラリを使って独自のプログラムをコンパイルする開発者向けです。

## 関連項目

`mbdefaults`、`mblevitus`、`mbotps`、`mbformat`。完全なリファレンスは MB-System のマニュアルページ mbconfig(1)（英語）です。
